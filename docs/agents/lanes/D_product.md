## Mission
A dashboard where a user picks a repo, types or dictates a question, watches the agent research live, and reads a cited answer with verified citations. Inference goes through Tinker sampling via lane A's driver; no Modal until day two.

## Gotchas for this lane
- SSE with FastAPI ≥ 0.135 is built in (`fastapi.sse`); otherwise `sse-starlette`. Plain fetch + ReadableStream on the client; the Vercel AI SDK expects its own protocol and is more work.
- Web Speech API needs HTTPS or localhost; Firefox is behind a flag; always keep the text box.
- Citations must be rendered from the same regex as the grader (`CITATION_RE` in contracts); do not write a second parser.
- Tinker checkpoint sampling clients take seconds to warm; create per profile at startup, not per request.
- Do not put secrets in the web app; the API holds them.
